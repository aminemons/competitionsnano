# Hardware Competitions · Micro & Nanoelectronics

Competition-only companion to the Worldwide Opportunity Atlas for a fourth-year ENSNN micro/nanoelectronics student.

**Read it:** `index.html` is a complete standalone page. Entries distinguish published 2026–27 calls, official early-access announcements, and historical previous editions. A published contest is not an offer of acceptance; verify Algerian citizenship, integrated-degree status, eligibility, team size, funding and shipment before entering.

**Important specific restrictions:** IEEE AP-S 2027 treats years 1–3 of five-year Bachelor-cum-Master degrees as undergraduate years and requires at least 50% undergraduate teammates. IEEE CASS 2027 requires *all* team members to meet undergraduate/high school classification until Dec 31, 2026. The year-four ENSNN classification requires written confirmation before treating the applicant as eligible.

**Sources and date:** Official organizer and IEEE publications inspected 2026-10-14. No invented acceptance chances or imaginary positions. Links appear on every entry.

**Hosting:** This repository contains a GitHub Pages deployment workflow. If Pages is not enabled, go to Settings → Pages and choose **GitHub Actions** as the publishing source. Pushing `main` then publishes via the action to the repository's Pages URL. Vercel Git linking may require renewed authorization for your team.
